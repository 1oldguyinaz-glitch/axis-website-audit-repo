# Axis audit funnel — launch checklist

## Required before publishing

- [ ] Replace the email address in `assets/js/config.js`.
- [ ] Deploy the Google Apps Script and paste the Web App URL into `config.js`.
- [ ] Submit at least three test leads from desktop and mobile.
- [ ] Confirm every test appears in Google Sheets.
- [ ] Record and insert the thank-you video.
- [ ] Update the privacy policy with the real business name and data processors.
- [ ] Confirm the promised delivery time is operationally realistic.
- [ ] Remove any claim that is not supported by evidence.
- [ ] Enable GitHub Pages from the repository `main` branch and `/ (root)`.

## Recommended after launch

- [ ] Add a custom domain.
- [ ] Set up a branded sender email.
- [ ] Add analytics only after the form works.
- [ ] Track visits, submissions, audits delivered, calls booked, and sales.
- [ ] Test one headline or CTA change at a time.

## Baseline metrics

Track weekly:

1. Qualified visitors
2. Form starts
3. Form submissions
4. Audits delivered
5. Replies or calls
6. Paid projects

Do not optimize the design based on opinions. Optimize the bottleneck shown by the data.
