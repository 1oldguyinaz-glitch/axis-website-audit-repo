# Client audit presentation workflow

1. Capture the website URL, business goal, and lead source.
2. Run the standardized audit checklist.
3. Save evidence screenshots.
4. Build the client deck using `sales-assets/Axis_Website_Growth_Audit_Client_Deck_Template.pptx`.
5. Recommend one package based on fit.
6. Explain why the lower tier would not fully solve the problem.
7. Explain why the higher tier would add cost without proportional value.
8. End with one next action: approve, defer, or decline.

Use the sentence:

> Our goal is not to sell you the largest package. It is to recommend the smallest complete solution that fixes the problems identified in your audit—without under-solving or overbuilding.
